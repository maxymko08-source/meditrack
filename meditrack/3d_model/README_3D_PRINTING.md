# MediTrack — Модульний 3D-корпус IoT диспенсера таблеток 💊
## Інженерна інструкція з 3D-друку, підгонки та складання (1:2 Gear Drive System)

Параметрична модульна 3D-модель розумного диспенсера таблеток для IoT-проєкту **MediTrack**, оснащена **підвищувальним зубчастим редуктором 1:2** для обертання барабана на повні **360°** за допомогою стандартного недорогого **180° сервоприводу SG90**. Всі посадки розраховані з технологічними зазорами **0.4 мм** для 3D-друку на FDM-принтерах.

---

## ⚙️ Кінематика зубчастої передачі 1:2 (180° Серво ➔ 360° Барабан)

Звичайні бюджетні мікросервоприводи SG90 повертаються лише в діапазоні **0°–180°**.
Завдяки циліндричній зубчастій передачі 1:2 під середньою декою:
- **Ведуча шестерня (Driver gear, 24 зуби, ділильний Ø 30 мм)** закріплена на валу сервоприводу.
- **Ведена шестерня (Driven gear, 12 зубів, ділильний Ø 15 мм)** розташована в центрі `(0, 0)`.
- Передавальне число: \(i = \frac{z_1}{z_2} = \frac{24}{12} = 2.0\).
- Міжосьова відстань: \(a = \frac{d_1 + d_2}{2} = \frac{30 + 15}{2} = 22.5\text{ мм}\).

**Таблиця кутів повороту:**
| Комірка барабана | Призначення | Кут барабана | Кут сервоприводу SG90 (0°–180°) |
|---|---|---|---|
| **Сектор 0** | **Home / Безпечна позиція (порожньо)** | **0°** | **0.0°** |
| **Сектор 1** | Понеділок (ПН) | **45°** | **22.5°** |
| **Сектор 2** | Вівторок (ВТ) | **90°** | **45.0°** |
| **Сектор 3** | Середа (СР) | **135°** | **67.5°** |
| **Сектор 4** | Четвер (ЧТ) | **180°** | **90.0°** |
| **Сектор 5** | П'ятниця (ПТ) | **225°** | **112.5°** |
| **Сектор 6** | Субота (СБ) | **270°** | **135.0°** |
| **Сектор 7** | Неділя (НД) | **315°** | **157.5°** |

## 🛠️ Порядок складання редуктора та диспенсера

1. **Встановлення електроніки:** Встановіть макетну плату 400 точок із ESP32 на дно нижнього корпусу. Порт Type-C співпадає з вікном на задній стінці. Встановіть LED (5 мм) та тактову кнопку (4.5 мм) у передні отвори.
2. **Монтаж сервоприводу:** Закріпіть сервомотор SG90 знизу деки у гніздо на відстані \(Y = +22.5\text{ мм}\) двома гвинтами M2.
3. **Монтаж шестерень:**
   - На вал сервоприводу одягніть штатну хрестовину, а на неї напресуйте **ведучу шестерню 24T** і зафіксуйте гвинтом валу M2.
   - Знизу у центральний отвір Ø 7.5 мм вставте **ведену шестерню 12T** так, щоб її зуби увійшли в зачеплення з ведучою 24T, а D-вал вийшов нагору над плоскою декою.
4. **Кріплення деки:** Опустіть середню деку на базовий короб і закрутіть 4 гвинти M3 у кутові стійки.
5. **Встановлення каруселі:**
   - Програмно встановіть сервопривід у кут **0°**.
   - Одягніть барабан-карусель на D-вал всередину опорного кільця так, щоб **Сектор 0 (Home)** опинився над отвором скидання.
   - Закрутіть короткий гвинт M3 з потаєм зверху в торець D-валу для надійної вертикальної фіксації барабана.
6. **Кришка:** Накрийте барабан пилозахисною кришкою.

## 💻 Скетч Arduino / ESP32 для сервоприводу 180° з редуктором 1:2

```cpp
#include <ESP32Servo.h>

Servo dispenserServo;
const int SERVO_PIN = 18;
const int LED_PIN   = 2;
const int BTN_PIN   = 15;

// Крок барабана: 45° на сектор
// Завдяки редуктору 1:2, крок серво = 45° / 2 = 22.5°!
// Сектор 0 (Home): 0.0° серво -> 0° барабан
// Сектор 1 (Пн):   22.5° серво -> 45° барабан
// Сектор 2 (Вт):   45.0° серво -> 90° барабан
// Сектор 3 (Ср):   67.5° серво -> 135° барабан
// Сектор 4 (Чт):   90.0° серво -> 180° барабан
// Сектор 5 (Пт):   112.5° серво -> 225° барабан
// Сектор 6 (Сб):   135.0° серво -> 270° барабан
// Сектор 7 (Нд):   157.5° серво -> 315° барабан

void setup() {
    Serial.begin(115200);
    pinMode(LED_PIN, OUTPUT);
    pinMode(BTN_PIN, INPUT_PULLUP);
    
    dispenserServo.setPeriodHertz(50);
    dispenserServo.attach(SERVO_PIN, 500, 2400);
    dispenserServo.write(0); // Стартова безпечна позиція Сектор 0
}

void dispenseDay(int dayNumber) { // dayNumber: 1 (Пн) .. 7 (Нд)
    float servoAngle = dayNumber * 22.5;
    digitalWrite(LED_PIN, HIGH);
    
    dispenserServo.attach(SERVO_PIN, 500, 2400);
    dispenserServo.write((int)servoAngle);
    delay(1200); // Час на поворот і викачування таблетки в лоток
    dispenserServo.detach(); // Вимикаємо ШІМ для тиші та економії енергії
    
    digitalWrite(LED_PIN, LOW);
}
```
