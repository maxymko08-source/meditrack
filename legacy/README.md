# Архів попередніх реалізацій

`backend_root` та `backend_nested` містять вихідний код, прочитаний перед
консолідацією. Файли Python мають суфікс `.py.txt`, щоб старі небезпечні тести
не потрапили до автоматичного запуску. Цей код не запускати.

Основний застосунок тепер лише в пакеті `meditrack`. Кореневі файли — короткі
сумісні точки входу. Конфігурація читає лише кореневий `.env`.
Файли `.env`, секрети та робочі БД до архіву не копіювалися.
Попередня MySQL БД не видаляється й не змінюється під час звичайного запуску.
