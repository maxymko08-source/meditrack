# Контрольна точка MediTrack

2026-11-17: збережено готові бекенд, міграцію, бота та 33 успішні тести попереднього етапу. Повторно не змінювалися.
Незавершено: нова CAD-геометрія, STL та перевірки, прошивка й апаратна документація.
Стару CAD-версію скопійовано в meditrack/3d_model/legacy перед заміною.
Рішення: 8 нерухомих комірок; поворотне дно 0°,20°,…160°; повернення лише після ручного спорожнення.

Етап CAD: design.py створює 7 STL у final/. Перевірено замкненість, орієнтацію, ребра, вироджені трикутники, 1 компоненту кожної деталі. Немає перетинів деталей складання, ротора на 161 позиції та висування лотка з кроком 2 мм. Зображення assembly.png та exploded.png створені. Фізичних перевірок немає.
Етап прошивки: додано ESP32 sketch і спільні кути mechanism.h; тест C++ послідовності компілюється g++ і проходить. Складання Arduino та випробування NVS на платі ще не виконано.

Етап інтеграції: нові 2/2 тести CAD–прошивка–HTTP пройшли, shared C++ перевірки пройшли. 8 STL, MeshLab: 0 самоперетинів. Додано wiring.svg, інструкцію прошивки та звіт VERIFICATION.md. Триває завантаження ESP32 toolchain для повної компіляції; результат ще не заявлений.

Контрольна точка після остаточної CAD-ітерації: 8 STL перебудовано, MeshLab 0 самоперетинів; тест узгодженості 2/2 пройшов. Корпус і посадки уточнено; старі моделі залишаються в legacy/. Прошивка також обробляє втрату NVS через uncertain без руху. Наступний крок: завершення встановлення Arduino-ESP32 3.3.13 у .tools/arduino і compile --fqbn esp32:esp32:esp32 firmware/MediTrack; після цього зафіксувати результат у VERIFICATION.md.

Остаточна геометрія: посадки SG90, плати, ріжка й основні зазори залежать від параметрів design.py; STL та переглядач SCAD перебудовано. Повторні перевірки змінених деталей: 0 самоперетинів, 0 колізій, контракт 2/2. Exploded view переглянуто візуально.

Завершено цифровий етап: повна прошивка скомпільована для ESP32 Dev Module, Flash 74%, RAM 14%. Остаточні 8 STL перевірені, 2 інтеграційні тести пройшли; всі результати у docs/VERIFICATION.md. Бекенд попереднього етапу збережено. Залишаються фізичні вимірювання, друк посадочних зразків, калібрування та випробування на пристрої за docs/OPERATION.md — їх тут не виконували.
